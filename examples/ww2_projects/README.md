# WW2期の計画機（meshkit の制作テスト）

meshkit だけで6機を作りました。形状、検査、テクスチャ、プレビュー、書き出しまで、すべて meshkit で行っています。
Blender は、書き出したファイルが正しいかを確かめるためにだけ使いました（`_blender_check/`）。

```
python build_all.py      # 6機を作り直す（out/ に OBJ・GLB・テクスチャ・プレビュー・summary.json）
```

`aero.py` は、この例のための航空機用の小さな部品集です（胴体のロフト、両翼を1つにつないだ主翼、折りたたみ翼の外翼、尾翼、プロペラ、脚、キャノピー、国籍標識の塗り分け）。中では meshkit の基本形状だけを使っています。

- 座標系は vehicleaddonww2 と同じです（+X＝左、+Y＝上、+Z＝前、1単位＝1m、原点＝主輪の接地点、z=0＝主輪の車軸）。
- 機体は水平姿勢で作っています。震電は地上で機首上げ5度ですが、水平のまま全輪が接地する脚にしました。XF5U は尾輪を1.85m浮かせてあり、機首を上げると地上角18.7度になります。全高が公表値と少し違うのはこのためです。
- どの機体も、閉じたメッシュの検査で問題0件、浮き部品0、6度刻みで1周回したプロペラの羽根がどこにも当たらないことを確かめています（`out/summary.json`）。折りたたみ翼（橘花・XF15C）は0〜110度で胴体などに当たらないことも確かめました（`out/folded_wings.png`）。

## 資料と妥協した点

各スクリプトの冒頭に、使った資料・寸法と、資料がなく推定した部分を書いています。要点は次のとおりです。

- 資料は公表寸法と配置の記述（Wikipedia 日・英、oldmachinepress.com の XF5U の記事）だけで、三面図からの採寸はしていません。
- 翼の根元と翼端の翼弦は、翼面積から割り出しました。
- 尾翼の大きさ、脚の位置、断面形、キャノピーの形は推定です。
- 震電：前翼の幅は3.0m、垂直尾翼は半翼幅の40%の位置としました。全長は英語版の9.66mを採りました（日本語版は8.889m）。
- 橘花：エンジンポッドは中心から1.65m、折りたたみ線はポッドのすぐ外側としました。
- 秋水：平面形は Me163 に近い形（前縁後退角23度、ねじり下げ4度）としました。塗装は試作機の橙色です。
- XB-42：プロペラ直径は4.0mとしました（資料なし）。主翼後縁の遠隔銃塔は格納状態として作っていません。
- XF15C：T尾翼は提案だけで終わったため、元の低い水平尾翼にしました。20mm機関砲は試作機に装備されていませんが、付けてあります。
- XF5U：円盤翼の平面形は翼弦の式で近似しました。実機のプロペラは2翅を2組重ねたものですが、4翅にしています。主脚は複輪ですが単輪にしました。塗装は推定（グロッシーシーブルー）です。

## ツールの確認（Blender は確認だけに使用）

`_blender_check/` にある結果です（共有用のzipには入れていません。同じ6機は `verify/models/` に確認用モデルとして入っていて、`verify/reference/blender/` に Blender で描いた画像があります）。

- **読み込み**：書き出した GLB と OBJ を Blender 5.2 に読み込み、6機とも次の点を確かめました。
  - オブジェクト数と三角形数が meshkit の報告と一致しました。
  - 外形寸法が一致しました。
  - 頂点を結合した後の非多様体の辺は0本、法線の向きの不一致も0本でした。
- **表示**：meshkit と同じカメラで Blender の Workbench 描画を行い、meshkit のプレビューと比べました。輪郭の一致率（IoU）は0.92〜0.96です（`blender_compare.png`）。差が出るのは、プロペラの羽根や銃身のような細い部品と、ガラスの表し方です。meshkit はmodと同じディザ、Blender はアルファしきい値で表示します。
- **別のPCでの再現**：お使いのPC（Python 3.12、numpy 2.5.3、Pillow 10.2.0）で6機を作り直すと、次のようになりました。
  - OBJ はクラウドで作ったものとバイト単位で一致しました。
  - テクスチャは画素・UVとも一致しました。PNG のファイルのバイト列だけは、Pillow のバージョンによる圧縮の違いで異なります。

## 制作中に見つかったツール側の課題

- **追加済み**：回転する部品の当たり判定 `check.clearance()` を meshkit 本体に追加しました。プロペラの羽根と主翼前縁の干渉（XF5U の初期配置）は、プレビューを見ただけでは気づきにくいためです。
- **例の側で対処**：翼端を丸めると、その分だけ全幅が公表値を超えていました。`aero.py` で、丸めた先端が指定した全幅で終わるように直しています。
- **例の側で対処**：キャノピーの前後の比率の合計が1以上になると、断面が重なってつぶれた面ができていました。`aero.py` で直しています。
- **未対応**：参照点（座席・銃口）の印は、部品に隠れていても描かれます。
- **未対応**：斜め視点（iso）の自動の画角合わせは、機体によっては余白が大きくなります。
